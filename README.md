# EXPERIMENT 1: ATM & BANKING SYSTEM
### NAME: NETHRAA N
### REG NO: 212224040217
# AIM:
To design and develop UML diagrams for an ATM and Banking System using StarUML to represent its structure and behavior.

# SRS (PROCEDURE):
1. Identify the system requirements and the four main entities: Customer, ATM, Bank Employee, and Manager.
2. Create a use case diagram to represent the interactions between actors and the system.
3. Draw a class diagram to represent the classes and their relationships.
4. Develop a sequence diagram to show the order of interactions between objects.
5. Create an activity diagram to represent the workflow of ATM operations.
6. Draw a package diagram and communication diagram to represent the system's organization and interactions.
7. Verify all diagrams for correctness and consistency.
